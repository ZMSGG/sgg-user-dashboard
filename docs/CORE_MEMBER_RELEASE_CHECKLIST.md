# コアメンバー限定公開 チェックリスト

対象: MY SGG Player OS を、デバッグ目的でコアメンバーだけに開くための手順。

このリリースは **公開ではない**。`public_access` は `false` のまま、検索インデックスは拒否のまま、
カスタムドメインは付けない。Sites のアクセス許可リストに個人を追加するだけで完了する。
本公開・独自ドメインは別のゲートであり、このチェックリストでは満たされない。

## 2. 2アカウント分離テスト（オーナー＋協力者1名）

`BLK-DISCORD-E2E-001` を閉じるための必須手順。自動テスト
（`tests/two-account-isolation.test.mjs`、6件）は実装の正しさを証明するが、
本番の設定と実アカウントでの確認を代替しない。

必要なもの: 同意した Discord アカウント2つ（オーナー＋協力者1名）。両方とも
SGG ギルドに参加していること。

### 手順

1. [ ] オーナーのアカウントで本番にログインし、マイSGG を開く
2. [ ] SGP 残高・付与履歴・Wallet アドレス・連携コードを控える
3. [ ] ログアウトする
4. [ ] 協力者のアカウントでログインする
5. [ ] **控えた値が一切表示されないことを確認する** — 特に:
   - [ ] SGP 残高が協力者自身の値（未付与なら 0）になっている
   - [ ] 付与履歴にオーナーの行が出ていない
   - [ ] Wallet 欄が未連携になっている
   - [ ] 連携コードがオーナーのものと違う
   - [ ] コレクション画面の保有数が協力者自身のもの（未連携なら「未接続」）
6. [ ] 協力者のアカウントで管理者機能に到達できないことを確認する
   - [ ] マイSGG に「ポイント付与（管理者）」欄が出ない
7. [ ] 両アカウントで同時にログインし（別ブラウザ／別プロファイル）、
      片方を再読み込みしてももう片方の情報が混ざらないことを確認する

1つでも該当したら **中止して報告する**。これは設定ミスではなく設計欠陥の可能性がある。

## 3. 権限記録（オーナー）

`rights/` に新しい権限記録を作る。既存の
`AUTH-SGG-USER-DASHBOARD-PRIVATE-DEPLOY-20260720-001` は
**オーナー1名のみ**の権限であり、閲覧者の追加を含まない。

記録に含めること:

- [ ] 追加する閲覧者の人数と、その範囲を「コアメンバーのデバッグ目的」と明記
- [ ] 承認したアセットのファイル名と SHA-256
- [ ] `public_access` を false のまま維持すること
- [ ] カスタムドメイン・検索インデックスを許可しないこと
- [ ] 2アカウント分離テストの実施日と結果

---

## 4. Sites への追加（オーナー）

- [ ] コアメンバーの ChatGPT アカウントを許可リストに追加する
- [ ] `access_mode` は `custom` のまま
- [ ] `public_access` が `false` のままであることを確認する
- [ ] `custom_domain_count` が `0` のままであることを確認する
- [ ] 追加後、許可していないアカウントで開けないことを1件確認する

---

## 5. デプロイ後の確認

- [ ] ホーム・プレイ・アリーナ・コレクション・コミュニティ・マイSGG の6画面が表示される
- [ ] 未ログインで `/api/passport`・`/api/holdings`・`/api/link/otomo-chain` が 401 を返す
- [ ] コンソールにアプリ由来のエラーが出ていない
- [ ] 320px 幅で横スクロールが発生しない

---

## このリリースで満たされないもの

以下は別のゲートであり、このチェックリストを通しても許可されない。

- 一般公開（`public_access: true`）
- 独自ドメイン（`my.sevengodsgames.com` 等）の付与
- 検索エンジンへのインデックス許可
- ギルド全体への開放
- SGP の付与実行
