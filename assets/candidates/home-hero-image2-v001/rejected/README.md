# Rejected iterations

Rejected binary iterations remain in the Codex generated-image store so the
repository does not carry duplicate multi-megabyte assets. They are not
candidates and must not be copied into `public/`, approved assets, or
production UI.

- Mobile-crop rejection: the GOD remained readable, but all or a material
  portion of the OTOMO fell outside the current mobile crop.
- Family-safety rejection: early 06 and 07 poses or torso emphasis did not meet
  the family-facing Home standard.

The built-in Image 2.0 originals remain in the Codex generated-image store.
